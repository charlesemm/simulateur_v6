Analyse

Simulation de référence

D'ici on programme les analyses, on suit les échanges avec l'outil de qualité, et on lit ce qu'il a retrouvé de ce qu'Echo a semé. Echo sait exactement quelles anomalies il a semées : il compare, puis ouvre d'un clic la ligne exacte qui a été manquée.

Planification

Echo tient le calendrier, il ne déclenche rien : à l'heure dite, il ouvre une échéance. Le script extérieur vient la lire, retire le jeu et pousse son rapport. Heures du serveur, fuseau Africa/Abidjan.

Aucune analyse programmée

Tant qu'aucune règle n'existe, aucune échéance ne s'ouvre et le script n'a rien à venir chercher.

Le taux de rappel est le nombre d'anomalies retrouvées sur le nombre d'anomalies semées ; la précision est le nombre d'anomalies justes sur le nombre d'anomalies signalées. Les anomalies sémantiques (orthographe, casse, caractères spéciaux) ne se repèrent qu'en comparant à un référentiel : un rappel plus bas y est normal.
